# 02 · 创作定义（Creation Definition）

> monkren 设计生命周期的**第 2 阶段**。决定做什么、探索多个方向、选一个——做设计前的"选方向"。

## 本阶段 skill

| Skill | 状态 | 用途 |
|-------|------|------|
| [generate-variations](./generate-variations/) | ✅ 活跃 | 同一设计产出 按要求数量的不同方案 |
| [wireframe](./wireframe/) | ✅ 活跃 | 低保真线框探索布局方案 |

## 阶段问什么

- **做什么**？——layout / 信息架构 / 流程
- **选哪个**？——比较有实质差异的方案

## 核心方法

- **按不确定性选保真度**——结构未知用线框，方向已明确可直接实现
- 用最便宜的方式探索最多的可能性
- 5 维度评审中的「创新性」从这阶段开始打分

## 阶段产物

- `wireframe` 输出：单一布局/流程默认 1 个，开放比较默认 3 个，数量服从用户
- `generate-variations` 输出：按要求数量的不同方案（未指定数量默认 3 个，媒介按请求）
- 用户选择 1 个方向 → 进入 03 设计执行
